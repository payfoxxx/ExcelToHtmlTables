# Excel to HTML Table Converter

Консольное приложение на .NET 8 для конвертации листов Excel в отдельные HTML-файлы с таблицами.

## 📋 Описание

Утилита преобразует файл Excel в набор HTML-страниц, где каждый лист исходного файла сохраняется как отдельный HTML-файл с таблицей. Приложение автоматически определяет количество столбцов на каждом листе и корректно отображает структуру данных.

## ✨ Особенности

- 📄 **Постраничная конвертация** — каждый лист Excel создается как отдельный HTML-файл
- 🔢 **Автоопределение столбцов** — автоматически обрабатывает листы с различным количеством столбцов
- 🎨 **Чистая HTML-разметка** — генерирует семантически правильные HTML-таблицы

## 📦 Требования

- [.NET 8 Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)
- [ClosedXML](https://www.nuget.org/packages/ClosedXML)
- Excel-файлы в форматах .xlsx или .xls

## 🚀 Установка

### Сборка из исходного кода

```bash
# Клонирование репозитория
git clone https://github.com/payfoxxx/ExcelToHtmlTables.git
cd excel-to-html-converter

# Восстановление зависимостей
dotnet restore

# Запуск с параметрами
dotnet run --InputExcelPath=путь_к_файлу_xlsx --OutputHtmlPath=путь_к_папке_html

# Запуск без параметров
Добавить свои переменные в файле appsettings.json и запустить проект
dotnet run
